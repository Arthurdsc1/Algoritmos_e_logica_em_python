# Algoritmos e Lógica de Programação em Python

Exercícios resolvidos em **Python** do curso **Algoritmos e Lógica de Programação**, do professor **Nélio Alves** (Udemy, 31 horas).

Este repositório traz uma seleção dos problemas do curso resolvidos em Python, com um arquivo `.py` por exercício.

## Conteúdo abordado

- Entrada e saída de dados
- Estruturas condicionais
- Estruturas de repetição 
- Vetores (listas)
- Matrizes

## Exercícios

| Arquivo | Tema |
|---|---|
| `crescente.py` | Ordem crescente |
| `diagonal_negativos.py` | Diagonal da matriz e valores negativos |
| `idades.py` | Exercício com idades |
| `menor.py` | Menor valor |
| `retangulo.py` | Cálculos com retângulo |
| `soma_impares.py` | Soma de números ímpares |
| `soma_vetor.py` | Soma dos elementos de um vetor |

## Como executar

É necessário ter o [Python 3](https://www.python.org/downloads/) instalado.

```bash
python nome_do_arquivo.py
```

Exemplo:

```bash
python retangulo.py
```

Em alguns sistemas (Linux/macOS), use `python3` no lugar de `python`.
